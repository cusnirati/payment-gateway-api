Building a basic payment gateway

https://en.wikipedia.org/wiki/Payment_gateway#Typical_transaction_processes
https://stripe.com/gb/resources/more/payment-gateways-101#how-does-a-payment-gateway-work

Intentionally kept simple so that it can demo software building principles like SOLID.
Certain things are omitted (verbosity in logs, authorization, https, http retries, configuration file validation, etc).

Logs more verbose than the console ones are in directory `z-logs`.
